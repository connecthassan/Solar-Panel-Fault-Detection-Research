# ☀️ Solar Panel Fault Detection Research

A deep learning research project focused on **solar panel fault classification** using multiple Convolutional Neural Network (CNN) architectures. The project evaluates different individual models and explores a **hybrid deep learning approach** to improve classification performance and fault detection accuracy.

## 🎯 Project Objectives

- Implement multiple CNN architectures for solar panel fault classification.
- Train and evaluate individual deep learning models.
- Compare model performance using different evaluation metrics.
- Develop and evaluate a hybrid deep learning approach.
- Analyze the effectiveness of combining different CNN architectures.

## 🧠 Implementations

| Implementation | Description |
|---|---|
| Individual Models | Training and evaluation of different CNN architectures independently. |
| Hybrid Model | Combining CNN architectures to explore improved classification performance. |
